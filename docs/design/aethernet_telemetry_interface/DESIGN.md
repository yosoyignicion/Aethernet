## Brand & Style

The design system establishes a high-precision, retro-futuristic telemetry console engineered for network engineers, systems architects, and cyber intelligence operators. It reimagines 1980s spacecraft instrumentation through the lens of modern, hyper-refined UI standards for 2080.

### Aesthetic Principles
- **Silent Precision:** Surfaces remain quiet, muted, and non-distracting to direct complete cognitive attention to diagnostic data, packet streams, and state changes.
- **Instrument Tactility:** Every interactive boundary, toggle, and display cell reads as a machined, solid-state electronic module. 
- **Functional Luminescence:** Accent colors function strictly as signal lights, state signifiers, and threshold warnings—never as decorative embellishments.
- **Strictly No Skeuomorphism or Nostalgia Kits:** No artificial scanlines, CRT flickers, chromatic aberration, or gaudy neon gradations. The retro-futuristic quality arises organically from dense typographic hierarchy, technical alphanumeric readouts, and strict grid discipline.

## Colors

The color architecture is built entirely upon a deep space foundation, using spectral accents exclusively for diagnostic differentiation and state indication.

### Surface System
- **Void Base (`#0A0E14`):** Canvas background; absolute zero-level foundation.
- **Surface Level 1 (`#11161F`):** Structural panels, side docks, and view canvases.
- **Surface Level 2 (`#1A2029`):** Interactive containers, cards, inspector panels, and cell tables.
- **Border Trim (`#232A36`):** Structural 1px separation lines defining hardware modules.
- **Interactive Hover Border (`#343E50`):** Subtle highlight indicator for interactive focus.

### Spectral Signals
- **Mint Green (`#00E5A0`):** Nominal telemetry, active connections, verified secure payloads, throughput peaks.
- **Cyan (`#00B8FF`):** Ingress/egress streams, routing paths, active interfaces, primary selection state.
- **Amber (`#FFB800`):** Latency spikes, buffer queue saturation, non-critical telemetry warnings.
- **Coral (`#FF4D6D`):** Packet drops, breached thresholds, critical intrusion alerts, service degradation.

### Typography Neutral Colors
- **Text High-Emphasis (`#F1F5F9`):** Primary readings, dynamic telemetry, critical labels.
- **Text Medium-Emphasis (`#94A3B8`):** Static identifiers, UI labels, table column headers.
- **Text Muted (`#475569`):** Timestamp watermarks, grid legends, structural unit labels.

## Typography

Typographic hierarchy relies on the division of three distinct typefaces, each serving a strict functional domain:

1. **Space Grotesk (Titles & Panel Headers):** Carries the technical, geometric personality of high-grade scientific apparatus. Used sparingly for view naming, module headers, and mode selections.
2. **Inter (Interface & System Content):** Neutral, hyper-legible, uncolored workhorse for standard prose, configuration fields, descriptions, and system prompts.
3. **JetBrains Mono (Telemetry, Values & Code):** Tabular numeric accuracy. Strictly applied to IP addresses, MAC IDs, frame counts, bitrates, latency indices, and categorical tags (`label-caps`). All dynamic values must run in JetBrains Mono to eliminate character jitter during high-frequency rerenders.

## Layout & Spacing

The layout is governed by a rigid 8px spatial grid, mapping to dense data operations.

### Multi-Panel Grid Model
- **Display Topology:** Modular multi-pane dashboard architecture. Content docks snap to vertical track dividers without arbitrary white space.
- **Desktop (>=1280px):** 12-column variable module system with 24px outer margins and 16px or 24px gutters. Secondary side rails adhere to fixed operational widths (e.g., 320px for packet inspector, 280px for interface hierarchy).
- **Tablet (768px - 1279px):** 6-column layout. Inspector docks collapse into modular drawer overlays. Gutter scales down to 16px.
- **Mobile (<768px):** Single-column stacked instrument blocks with 16px margins. Telemetry ribbons adopt horizontal scroll carousels with fixed-width data blocks.

## Elevation & Depth

Visual depth is strictly flat-layered and planar. Drop shadows are completely prohibited to maintain absolute instrument clarity and prevent visual mud.

### Structural Stratification
- **Plane 0 (Canvas):** `#0A0E14` acts as the frame chassis.
- **Plane 1 (Module Deck):** `#11161F` forms the secondary surface for major functional groupings, bounded by a 1px solid border (`#232A36`).
- **Plane 2 (Sub-Instrument Cells):** `#1A2029` forms the interactive wells, metric containers, and nested row states.
- **Floating Overlays & Menus:** Retain `#1A2029` fill with an elevated border accent (`#343E50`) and a backdrop filter of `blur(8px)` with 95% opacity to maintain contextual awareness of the background telemetry streams.
- **Signal Highlights:** Active focus or armed states project a 1px border colored with the respective status accent (`#00E5A0`, `#00B8FF`, etc.), complemented by a crisp 2px hairline outer focus ring with 15% opacity of the same hue.

## Shapes

Every container, viewport, control trigger, and sensor tag adheres to a consistent 12px radius (`rounded-lg` token mapping) to maintain the sleek ergonomic profile of machined modern aerospace hardware.

### Radius Assignments
- **Major Panels & Cards:** `12px` (Tokens: `0.75rem` / `rounded-lg`).
- **Inputs, Buttons, and Data Cells:** `8px` to `12px` dependent on nested boundary context.
- **Status Dots & Pulse Radiators:** Fully circular (`9999px`) to contrast against rectangular grid modules.
- **Hairlines:** Crisp, single-pixel geometry across all separators and bounding boxes.

## Components

### Buttons & Arming Triggers
- **Primary Action (Execute/Commit):** Background `#00E5A0`, text `#0A0E14` (Space Grotesk Medium), border none, corner radius 12px. Hover: brightness 108%. Active: brightness 95%.
- **Secondary Action (Inspect/Filter):** Background `#1A2029`, text `#00B8FF`, border 1px solid `#232A36`, corner radius 12px. Hover: border `#00B8FF`.
- **Destructive/Abort:** Background `rgba(255, 77, 109, 0.1)`, text `#FF4D6D`, border 1px solid `#FF4D6D`. Hover: background `rgba(255, 77, 109, 0.2)`.

### Chips & Sensor Badges
- Constructed with `label-caps` in JetBrains Mono.
- Padding: 4px vertical, 8px horizontal; corner radius 12px.
- **Format:** Inactive badges use `#1A2029` background with `#94A3B8` text. Active telemetry badges use 10% opacity tints of the parent status color (`#00E5A0`, `#00B8FF`, `#FFB800`, `#FF4D6D`) with 100% solid text and matching 1px border.

### Telemetry Cards & Metric Blocks
- Background `#11161F`, border 1px solid `#232A36`, corner radius 12px, padding `1.5rem`.
- Header: Metric title in `label-caps` (`#94A3B8`) paired with an operational status indicator (6px circle).
- Value Readout: `telemetry-xl` JetBrains Mono in `#F1F5F9` with unit identifier in `telemetry-sm` `#475569`.

### Input Fields & Search Bars
- Background `#11161F`, border 1px solid `#232A36`, text `#F1F5F9`, typography Inter 14px.
- Focus: Border snaps to `#00B8FF` with zero drop shadow.
- Prefix/Suffix: Network protocol tags (e.g., `tcp://`, `port:`) rendered in JetBrains Mono `#475569`.

### Checkboxes & Segmented Toggles
- **Checkboxes:** 16x16px square with 4px border radius. Unchecked: 1px border `#232A36`, background transparent. Checked: `#00E5A0` background with dark checkmark.
- **Segmented Controls:** Enclosed container `#11161F` with 12px radius. Active tab slides with background `#1A2029`, border 1px solid `#343E50`, and text `#00E5A0`.

### Data Grids & Packet Lists
- Header: JetBrains Mono `label-caps` in `#94A3B8` with an explicit bottom border 1px solid `#232A36`.
- Rows: Alternating hover state with `#1A2029` background. Selected row displays a 2px vertical lead line in `#00B8FF` against `#11161F` fill.
- Numbers & Coordinates: Fixed-width monospaced formatting with leading zeros muted in `#475569`.
