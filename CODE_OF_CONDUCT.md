# Código de conducta

## Nuestro compromiso

Como participantes, nos comprometemos a hacer de este proyecto un espacio
respetuoso y libre de acoso para todo el mundo, con independencia de edad,
cuerpo, discapacidad, etnia, identidad y expresión de género, nivel de
experiencia, nacionalidad, apariencia, religión u orientación sexual.

## Normas

Ejemplos de comportamiento que construyen comunidad:

- Tratar con respeto y empatía.
- Aceptar críticas constructivas con elegancia.
- Priorizar lo mejor para la comunidad y el usuario.

Comportamiento inaceptable:

- Lenguaje o imágenes sexualizadas, y atención sexual no deseada.
- Insultos, comentarios despectivos y ataques personales o políticos.
- Acoso público o privado.
- Publicar información privada de terceros sin permiso.

## Aplicación

Los mantenedores aclaran las normas y pueden retirar, editar o rechazar
contribuciones que no se ajusten a este código, comunicando los motivos cuando
sea apropiado.

Reporta conductas abusivas a los mantenedores del repositorio. Las quejas se
revisan e investigan con confidencialidad.

Este código está adaptado del [Contributor Covenant](https://www.contributor-covenant.org/es/),
versión 2.1.
